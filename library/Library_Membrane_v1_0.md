## ⭐ 2 — Membrane Rules (LM‑Series)

### **LM‑1 — Structural‑Only Admission**
```
Only structural scaffolding artifacts may enter the Library Layer.
Runtime, protocol, or band-layer artifacts are prohibited.
```

### **LM‑2 — Temporal Classification Enforcement**
```
Temporal artifacts must follow the Temporal Artifact Classification Standard
v1.0. Anchoring applies unless invariants are defined; pinning applies unless
those invariants are temporal.
```

### **LM‑3 — Provenance Requirement**
```
All library artifacts must include identity blocks, altitude declarations,
non-activation clauses, and version stamps.
```

### **LM‑4 — Altitude Containment**
```
Library artifacts must remain within A10–A12. No implicit altitude changes are
allowed.
```

### **LM‑5 — Drift-Neutrality**
```
The membrane enforces drift-neutral semantics. No artifact may introduce
conceptual leakage or semantic drift across altitudes.
```

### **LM‑6 — Lineage Anchoring**
```
Lineage-dependent artifacts are anchored. Invariant artifacts are pinned.
Temporal invariants revert to anchoring.
```
