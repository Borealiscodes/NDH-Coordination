# ⭐ **NDH‑Coordination Subsystem Map v1.0**  
### *Subsystem Boundaries • Routing Geometry • Altitude‑Neutral Mapping*

## **1. Purpose**

The Subsystem Map defines **where each NDH subsystem sits**, **how it relates to the altitude stack**, and **how Coordination routes artifacts between them**.

It does **not**:

- interpret semantics  
- evaluate algebra  
- activate simulations  
- rewrite artifacts  
- impose style  

It is strictly **routing‑only**.

---

## ⭐ **2. Subsystem Overview**

NDH contains **five altitude‑specific subsystems** and **one altitude‑neutral membrane**:

- **Constellation** — semantic substrate  
- **Triadic‑Core** — algebraic backbone  
- **Simulation‑Suite** — geometric/runtime substrate  
- **Provenance Layer** — lineage substrate  
- **Research‑Pilot** — exploratory mixed‑altitude layer  
- **NDH‑Core Architecture** — structural backbone  

Coordination sits **outside** this stack, acting as the altitude membrane.

---

## ⭐ **3. Subsystem Map Table (v1.0)**

| Subsystem | Altitude | Role | Routing Behavior | Drift Risk |
|----------|----------|------|------------------|------------|
| **Research‑Pilot** | 0 | Exploratory, chaotic, mixed‑altitude | Decompose raw artifacts; route components upward | High (semantic–algebra–geometry collapse) |
| **Constellation** | 1 | Semantic substrate | Route semantic components here | Medium (semantic overreach) |
| **Triadic‑Core** | 2 | Algebraic backbone | Route algebraic structures here | Medium (symbolic drift, geometry adjacency) |

This table is the **canonical subsystem geometry** for NDH‑Coordination.

## ⭐ **5. Coordination Rules for Subsystems**

### Coordination DOES:
- detect subsystem altitude  
- decompose mixed artifacts  
- route components to correct subsystems  
- preserve flavor rights  
- prevent drift  
- maintain NDH coherence  

### Coordination DOES NOT:
- rewrite subsystem artifacts  
- activate subsystem logic  
- impose semantics or algebra  
- run simulations  
- govern subsystem behavior  

This is the correct posture.
