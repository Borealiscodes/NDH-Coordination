## ⭐ 2 — Didactic Clause (DC‑1)

This is your philosophical dad joke, elevated to constitutional status:

```
Temporal artifacts are anchored, not pinned —
unless they define invariants, in which case they are pinned,
unless those invariants are temporal, in which case they are anchored.
```

### Why this works  
- It teaches the rule.  
- It encodes lineage logic.  
- It preserves altitude discipline.  
- It is non‑activating.  
- It is reversible.  
- It is funny in the way NDH governance often is.

## ⭐ 3 — Structural Interpretation (SI‑Series)

### **SI‑1 — Anchoring Rule**
```
Temporal artifacts attach to lineage → therefore anchored.
```

### **SI‑2 — Invariant Exception**
```
If a temporal artifact defines an invariant → it is pinned.
```

### **SI‑3 — Temporal Invariant Exception**
```
If the invariant itself is temporal → anchoring overrides pinning.
```

### **SI‑4 — Drift-Neutrality**
```
Anchoring ensures reversible temporal behavior; pinning ensures stability.
The clause governs which applies.
```
