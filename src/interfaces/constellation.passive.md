# ⭐ **NDH‑Coordination Constellation Passive Interface v1.0**  
### *Passive Boundary • Semantic Routing • Altitude‑Neutral Interface*

## **1. Purpose**

This passive interface defines **how NDH‑Coordination interacts with NDH‑Constellation**, the semantic substrate of NDH.

It is strictly **non‑activating**:

- Coordination does **not** interpret semantics  
- Coordination does **not** evaluate meaning  
- Coordination does **not** rewrite semantic content  
- Coordination does **not** govern Constellation  

It only **routes semantic components** to Constellation.

---

## ⭐ **2. Interface Role**

Constellation is the **semantic altitude** of NDH.

Coordination’s role is to:

- detect semantic components  
- isolate semantic framing  
- preserve metaphor/narrative flavor  
- route semantic content upward  
- prevent semantic → algebra drift  
- prevent semantic → geometry drift  

This interface defines that boundary.

---

## ⭐ **3. Semantic Indicators (Passive)**

Coordination identifies semantic content using **passive indicators**, not interpretation:

- metaphor  
- narrative  
- conceptual framing  
- descriptive language  
- mythic or symbolic phrasing  
- semantic scaffolding  
- expressive drift  

These indicators trigger routing to Constellation.

---

| Component Type | Indicator | Routing Behavior | Notes |

| **Semantic Framing** | metaphor, narrative, conceptual language | Route to **Constellation** | No interpretation |

This table defines the **semantic boundary**.

---

## ⭐ **5. Interface Rules**

### **Rule 1 — Passive Only**  
Coordination does not interpret semantic meaning.

### **Rule 2 — Non‑Destructive**  
Semantic components are preserved exactly as written.

### **Rule 3 — Flavor Rights**  
Constellation receives semantic flavor intact.

### **Rule 4 — No Semantic Activation**  
Coordination does not trigger semantic expansion or semantic inference.

### **Rule 5 — No Semantic Normalization**  
Coordination does not sanitize metaphor or narrative.

---

## ⭐ **6. Routing Flow**

```
Artifact enters Coordination
   ↓ detect semantic indicators
Isolate semantic components
   ↓ route to Constellation
Preserve flavor rights
   ↓ prevent semantic → algebra drift
Coordination remains altitude-neutral
```

This is the correct semantic routing posture.
