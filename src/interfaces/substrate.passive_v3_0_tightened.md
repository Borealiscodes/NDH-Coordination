## **3 — Reversible Routing Conditions**

Substrate is the **lowest membrane**, receiving descent from:

- A12 constellation  
- A11 zen‑bridge  
- A11–A12 continuity  
- A12 posture  

### Allowed routes:

- continuity → substrate  
- posture → continuity → substrate  
- zen‑bridge → continuity → substrate  
- constellation → posture → continuity → substrate  

### Allowed ascent:

- substrate → continuity → posture → constellation  
- substrate → continuity → zen‑bridge → constellation  

### Forbidden:

- substrate → constellation (direct)  
- substrate → zen‑bridge (direct)  
- substrate → expressive activation  
- substrate → rendering grammar  

### Reversal guarantee:

```
A12 → posture → continuity → substrate → continuity → posture → A12
```

Substrate must return the system to the same altitude‑aligned posture state.

- substrate ↔ governance engines

## **5 — Continuity‑Anchored Descent**

Substrate must only be reached through continuity.

### Warm anchors (upward):

- posture stabilization  
- constellation re‑entry  
- altitude ascent sealing  

### Cold anchors (downward):

- posture compression  
- continuity descent  
- altitude descent sealing  

### Posture‑aware behavior:

- **stable:** substrate reachable via continuity  
- **transitional:** anchor-first descent  
- **expressive:** substrate unreachable (sealed)

## **6 — Closure Condition**

Substrate routing is **closed** when:

- invariants remain intact  
- adjacency constraints remain safe  
- reversible routing is valid  
- continuity alignment is correct  
- no drift, collapse, inversion, or absorption occurs  

Failure modes:

- altitude collapse  
- membrane inversion  
- expressive leakage  
- continuity bypass attempts
