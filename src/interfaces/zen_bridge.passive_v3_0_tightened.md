#### 3 — Reversible routing conditions

**Role of zen‑bridge:**  
A11 is the **bridge membrane** between:

- A12 — constellation  
- A11–A12 — continuity  
- A10 — substrate (via continuity and posture)

**Allowed routes (schematic):**

- A12 → A11 (constellation → zen‑bridge)  
- A11 → A11–A12 (zen‑bridge → continuity)  
- A11–A12 → A11 (continuity → zen‑bridge)  
- A11 → A12 (zen‑bridge → constellation)

**Forbidden:**

- direct A11 → A10 without continuity/posture  
- A11 → expressive activation layers  
- A11 → governance engines  

**Reversal guarantee:**

Any zen‑bridge traversal must be reversible:

```text
A12 → A11 → A11–A12 → A11 → A12
```

Return must preserve posture state and altitude discipline.

Zen‑bridge adjacency must remain:

- expressive‑neutral  
- governance‑neutral  
- altitude‑safe  
- membrane‑sealed  

**Legal adjacency:**

- A11 ↔ A12 (constellation)  
- A11 ↔ A11–A12 (continuity)  
- A11 ↔ A11 (self‑adjacent)

**Forbidden adjacency:**

- A11 ↔ A10 (direct substrate)  
- A11 ↔ expressive geometry  
- A11 ↔ rendering grammar

#### 5 — Continuity alignment

Zen‑bridge must align with continuity envelopes:

**Warm anchors (upward):**

- constellation re‑entry  
- altitude ascent sealing  
- stable posture ascent via continuity

**Cold anchors (downward):**

- constellation exit  
- altitude descent sealing  
- stable posture descent via continuity

**Posture‑aware behavior:**

- **stable:** direct zen‑bridge ↔ continuity adjacency  
- **transitional:** anchor via continuity before constellation/substrate  
- **expressive:** zen‑bridge only in constellation‑adjacent, non‑activating mode  

---

#### 6 — Closure condition

Zen‑bridge routing is considered **closed** when:

- invariants remain intact  
- adjacency constraints remain safe  
- reversible routing is valid  
- continuity alignment is correct  
- no drift, collapse, inversion, or absorption occurs across A11

Failure modes:

- constellation–substrate shortcut attempts  
- adjacency corruption  
- altitude misalignment  
- membrane inversion at A11
