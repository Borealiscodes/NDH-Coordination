## ⭐ **2 — Passive Interface Specification (v3.0)**

### **PI‑1 — Translation‑Safe Constraint**
Zen‑Bridge must enforce:

- posture‑aligned translation  
- expressive‑neutral traversal  
- sealed‑substrate movement  
- non‑activating adjacency  

### **PI‑2 — Altitude Boundary**
Zen‑Bridge sits at **A11**, between:

- A12 (Constellation / Posture Skeleton)  
- A10 (NDH‑Coordination Routing Skeleton)  

It is the **only legal traversal path** between these altitudes.

### **PI‑3 — Posture Discipline**
Zen‑Bridge must respect posture states:

- stable → direct translation  
- transitional → continuity‑anchored translation  
- expressive → constellation‑adjacent translation  

### **PI‑4 — Drift‑Prevention**
Zen‑Bridge must prevent:

- expressive leakage  
- altitude collapse  
- membrane inversion  
- subsystem absorption  

### **PI‑5 — Continuity Anchors**
Zen‑Bridge must apply:

- warm anchors for upward stabilization  
- cold anchors for downward stabilization  

### **PI‑6 — Routing Discipline**
Zen‑Bridge must route through:

- **continuity.passive_v3_0.md**  
- **posture.passive_v3_0.md**  

No direct NDH ↔ Constellation routing.
