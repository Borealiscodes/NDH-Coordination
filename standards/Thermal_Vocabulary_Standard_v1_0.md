## ⭐ 2 — Thermal Vocabulary Definitions (TV‑Series)

### **TV‑1 — Active‑Warm Layer**
```
Definition:
    A conceptual layer in active circulation. Altitude-bounded, membrane-
    protected, drift-neutral, and lineage-anchored. Contains structural
    scaffolding artifacts currently in use.

Usage:
    Library Layer (A10–A12)
```

### **TV‑2 — Archival‑Cold Layer**
```
Definition:
    A sealed, inert, non-interactive, non-governance layer used for archival
    storage of retired or superseded artifacts. No altitude transitions occur
    within this layer.

Usage:
    NDH-PROVENANCE
```

### **TV‑3 — Warm-Stable**
```
Definition:
    An active-warm artifact whose lineage is anchored. Stability derives from
    altitude anchoring rather than invariants.

Usage:
    Anchored artifacts (lineage-dependent)
```

### **TV‑4 — Warm-Volatile**
```
Definition:
    An active-warm artifact whose behavior is governed by invariants. Volatility
    derives from pinning rather than anchoring.

Usage:
    Pinned artifacts (invariant-dependent)
```

### **TV‑5 — Warm-to-Cold Routing**
```
Definition:
    The process of retiring an active-warm artifact into archival-cold storage.
    Involves lineage freezing, version sealing, and removal from active
    governance.

Usage:
    Library → NDH-PROVENANCE
```

### **TV‑6 — Cold-to-Warm Retrieval**
```
Definition:
    The process of reintroducing an archival-cold artifact into active-warm
    circulation. Requires re-anchoring, re-indexing, and re-membraning.

Usage:
    NDH-PROVENANCE → Library (rare)
```

## ⭐ 3 — Didactic Clause (DC‑1)

```
Temporal artifacts are anchored, not pinned —
unless they define invariants, in which case they are pinned,
unless those invariants are temporal, in which case they are anchored.
```

This clause governs thermal classification behavior.
