## ⭐ 2 — Clause Text (IC‑Series)

### **IC‑1 — Recognition Clause**
```
NDH-Coordination and NDH-Constellation jointly recognize the Rules and Concepts
Crosswalk v1.0 as the authoritative semantic bridge between structural rules
and conceptual ontology.
```

### **IC‑2 — Binding Clause**
```
The Crosswalk v1.0 is hereby bound to both altitudes. Coordination must consult
the Crosswalk when defining rules; Constellation must consult the Crosswalk
when defining concepts.
```

### **IC‑3 — Membrane Clause**
```
The Crosswalk v1.0 is protected by a bidirectional semantic membrane. Rules
may reference concepts only through the Crosswalk; concepts may reference rules
only through the Crosswalk.
```

### **IC‑4 — Drift-Neutrality Clause**
```
The Crosswalk v1.0 prevents semantic drift between altitudes by enforcing
consistent interpretation of boundaries, hierarchies, grammars, and processes.
```

### **IC‑5 — Non-Activation Clause**
```
Integration of the Crosswalk v1.0 does not activate geometry, routing,
runtime languages, or sealed-layer logic. All bindings remain structural-only.
```
